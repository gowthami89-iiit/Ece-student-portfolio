# ECE Student Portfolio

A responsive single-page portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure/content
- `style.css` — design, layout and responsive styles
- `script.js` — mobile navigation, reveal animations and cursor glow
- `assets/hero-study.png` — starter hero image

## Before publishing
1. Replace `Your Name` with your real display name.
2. Update the About, Education, Experience and Project text with your exact information.
3. Add your real GitHub and LinkedIn URLs.
4. Put your PDF resume at `assets/resume.pdf`.
5. Replace project placeholder links with real repositories/demos.
6. If you later create a working portfolio animation, add it under `assets/` and swap it into the hero.

## Run locally
Open `index.html` in a browser. For a smoother development workflow, use VS Code with a local server extension.

## Publish
This is a static site, so it can be hosted with GitHub Pages.
